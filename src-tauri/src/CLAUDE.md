# Read the home-root contract first

**`~/AGENTS.md`** (identical twin: `~/.claude/CLAUDE.md`) is the operating contract
for every repo here. It is the only one John maintains by hand. Read it before you
touch code, and prefer it over anything nested — nested copies drift, that one does not.

Do **not** treat this file's existence as evidence of a repo-local contract. If a repo
has real local documentation it is named below; otherwise there is none and the
home-root file is the whole agreement.
